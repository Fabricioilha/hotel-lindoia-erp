# Cópia local do Realtime Database

Salve aqui a exportação JSON da **raiz** do Realtime Database com o nome `production-rtdb.json`. A exportação precisa conter `erp_geral/escala`, incluindo `days` e `employees`; o importador recusa arquivos sem esses dados para não iniciar a simulação sem a escala.

O arquivo JSON e os dados salvos pelo emulador são ignorados pelo Git, pois podem conter informações pessoais. Não envie essa cópia para o repositório.
